Give an agent a script and a phone number, and it makes the call. It speaks
Hindi, English and the Hinglish that most real calls are in, and it runs on
GPUs, models and SIP lines we own in India.

Voice agents cost ₹1 a minute on the volume plan, or ₹5 a minute pay as you go.
Every company starts on pay as you go. See [Billing & tiers](/general/tiers),
or compare the plans on the [pricing page](https://voice.miraiminds.co/pricing).

## Get a key

Create a key in the [console](https://sandbox.voice.miraiminds.co) under
**Developers**. You do not need an access code: the console asks for your
work email, and you can create the key once you confirm it from the mail. The
console shows the key only once. You can rotate or revoke it on the same page.

Every request is plain HTTPS with one `Authorization` header, so it works from
any language. This places a call with an agent you have already created:

```bash
curl -X POST https://sandbox.voice.miraiminds.co/v2/calls \
  -H "Authorization: Bearer $MIRAI_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: order-8842-confirm-1" \
  -d '{"agent_id": "agt_01JZQ8F3K7M2N5P9R4T6V8W0XZ", "to": "+919876543210"}'
```

There is no SDK to install. Start with the [Quickstart](/v2/quickstart), which
creates an agent and places a first call in cURL, Python and Node. The
[API reference](/api-reference/introduction) covers every endpoint, and the
[Postman collection](/api-reference/postman) has each request ready to send. If
you build on Pipecat, use the [`pipecat-mirai`](/v2/pipecat) package.
