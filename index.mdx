## Get a key

Create a key in the [console](https://sandbox.voice.miraiminds.co) under
**Developers**. You do not need an access code: the console asks for your
work email, and you can create the key once you confirm it from the mail. The
console shows the key only once. You can rotate or revoke it on the same page.

```bash
pip install --extra-index-url https://sandbox.voice.miraiminds.co/pypi/simple mirai-voice
```

```python
from mirai import Mirai

mirai = Mirai()                                  # reads MIRAI_API_KEY

agent = mirai.agents.create(
    name="Order confirmation",
    system_prompt="You are आशु from Acme. Confirm the order and ask whether the delivery address is unchanged.",
    first_message="नमस्ते, मैं Acme से आशु बोल रहा हूं।",
    voice_id="ashu",
    language="hi",
)

call = mirai.calls.create(agent_id=agent.id, to="+919876543210")
print(mirai.calls.wait(call.id).status)          # 'completed'
```

If you would rather use plain HTTP, every page in these docs also shows each
request in cURL, Python and Node. Start with the [Quickstart](/v2/quickstart).
