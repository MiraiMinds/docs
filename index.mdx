## Your first call

Open **Developers** in the [sandbox](https://sandbox.voice.miraiminds.co/#/developers)
and press **Create key**. The first time, give your work email. The key is
shown once, so put it in your secret manager. Then create an agent:

```bash
curl -X POST https://sandbox.voice.miraiminds.co/v2/agents \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Order confirmation",
    "system_prompt": "You are Ashu from Acme. Confirm the order and ask whether the delivery address is unchanged. Keep replies short. When the customer is done, thank them and end the call.",
    "first_message": "नमस्ते, मैं Acme से आशु बोल रहा हूँ।",
    "voice": { "voice_id": "ashu", "language": "hi-IN" },
    "language": "hi-IN"
  }'
```

Then call a phone you are allowed to call, with the `id` you got back:

```bash
curl -X POST https://sandbox.voice.miraiminds.co/v2/calls \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "agent_id": "agt_01JZQ8F3K7M2N5P9R4T6V8W0XZ", "to": "+919876543210" }'
```

The [Quickstart](/v2/quickstart) has both requests in Python and Node, and the
webhook that tells you how the call went. When you are ready for real traffic,
[go live](/v2/go-live) and send the same requests to
`https://prod.voice.miraiminds.co`.

Every company starts on T5. T1 is ₹1 a minute for the voice AI, plus ₹0.30 for
our phone line and ₹0.20 for call insights; T5 and T3 include both. Calls are
billed in 10-second blocks. Prices exclude GST.
[Billing & tiers](/general/tiers) has every plan and how a call is billed. The
speech APIs have their own prices on the
[Speech API](/v2/speech#languages-and-prices) and
[language model](/v2/llm) pages.
