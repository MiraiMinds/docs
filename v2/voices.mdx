---
title: Voices
description: How to choose a voice_id for your agent. The catalogue is the same on every tier, and the language field has one caveat.
---

Every agent speaks in one voice, set by `voice.voice_id`. Every
[tier](/general/tiers) uses the same Mira voices, so the catalogue does not
change with your plan.

## The catalogue

| `voice_id` | Voice |
| :--- | :--- |
| `ashu` | Male |
| `neha` | Female |
| `shruti` | Female |
| `sameer` | Male |

All four are Hindi voices that code-switch into English the way real Indian
speech does. **`voice` is required** when you create an agent. A voice outside
the catalogue is rejected when you create the agent, with an error that names
the allowed set:

```json title="400 Bad Request"
{
  "error": {
    "code": "invalid_request",
    "message": "unknown voice_id \"priya\" — voice.voice_id must be one of ashu, neha, sameer, shruti"
  }
}
```

<Note>
Because the catalogue is the same on every tier, an agent's voice never depends
on your plan. Moving to a different plan changes what your calls cost and
leaves the way they sound unchanged.
</Note>

## Hearing them first

`GET /v2/voices`, with your API key, returns the live catalogue: each voice's
`voice_id`, its name and its language. It has no audio samples, so open Agent
Studio in the [console](https://sandbox.voice.miraiminds.co) to hear each voice
before you commit to one. The name in the picker is the `voice_id`. The
catalogue grows monthly, so if this page and the API disagree, trust the API.

```json title="GET /v2/voices"
{
  "data": [
    { "voice_id": "ashu", "name": "आशु", "language": "hi" },
    { "voice_id": "neha", "name": "नेहा", "language": "hi" },
    { "voice_id": "shruti", "name": "श्रुति", "language": "hi" },
    { "voice_id": "sameer", "name": "समीर", "language": "hi" }
  ]
}
```

<Tip>
**Listen before you pick.** Voice choice affects answer-through rates more than
prompt wording does.
</Tip>

## Setting a voice on an agent

```json
{
  "name": "Order confirmations",
  "system_prompt": "…",
  "voice": { "voice_id": "ashu", "language": "hi-IN" },
  "language": "hi-IN"
}
```

| Field | Type | Description |
| :--- | :--- | :--- |
| `voice_id` | string | **Required.** A voice from [the catalogue](#the-catalogue), which is the same on every tier. An unknown voice returns `400`. |
| `language` | string | Rendering language. Omit it to inherit the agent's top-level `language`. **Accepted and stored, but not yet honoured.** See below. |

Change it later with `PATCH /v2/agents/{id}`:

```bash
curl -X PATCH https://sandbox.voice.miraiminds.co/v2/agents/agt_… \
  -H "Authorization: Bearer sk_live_…" \
  -H "Content-Type: application/json" \
  -d '{ "voice": { "voice_id": "neha", "language": "hi-IN" } }'
```

See the [Agents reference](/v2/agents#voice) for the full agent shape.

## The language caveat

<Warning>
**`voice.language` is recorded, not yet applied**

We validate it, store it, echo it back and carry it with the call payload, but
the voice renders in the agent's top-level `language`. If the two match, you
get what you expect. If they differ, the top-level one wins.
</Warning>

Keep `voice.language` and the agent's `language` identical.
