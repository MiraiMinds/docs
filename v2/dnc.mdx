The **do-not-call list** is a per-workspace set of phone numbers that no call
from your workspace rings. Once a number is on it,
[`POST /v2/calls`](/v2/calls#do-not-call-is-always-on) refuses it with
`422 do_not_call`, a scheduled callback to it is not placed, and every
[campaign](/v2/campaigns) in the workspace skips it, whether the campaign is
running, paused or not yet created.

Numbers get on the list three ways: you add them, a person asks on a call not
to be called again, or a person files a TRAI complaint about one of your calls.
See [how numbers get on the list](#how-numbers-get-on-the-list).

Base URL `https://sandbox.voice.miraiminds.co`.

<Warning>
**This is your suppression list, not the national registry.**

It suppresses numbers for *your* calls and campaigns on *our* platform. It is
separate from TRAI's DND/NCPR register, and we do not scrub against that register for
you. The consent and DND obligations sit with the business placing the calls,
and putting a number on this list does not meet them. See
[India calling rules](/v2/limits#india-calling-rules).
</Warning>

## How suppression works

Every call is checked before it is placed. `POST /v2/calls` answers
`422 do_not_call` before anything is reserved or charged, and the message says
why the number is listed. Campaigns check numbers **at dial time**, in the same
step that hands contacts to the dialler. This has three consequences:

- **Late additions work.** A number added while a campaign is running is
  suppressed from that moment on, even though it was uploaded in the original
  list.
- **Suppression is not deletion.** The contact stays in the campaign with
  [`status: "suppressed"`](/v2/campaigns#contact-statuses) and shows up in the
  report, so you can prove the number was uploaded and not called.
- **Suppressed contacts are never billed.** We never dial them, so there are
  no minutes to charge.

The check cannot be turned off, for single calls or for campaigns. To call a
number again, for example when a person who asked to stop now asks you to call,
[remove it](#remove-a-number) first.

## How numbers get on the list

| `source` | How it got there |
| :--- | :--- |
| `manual` | You added it with [`POST /v2/dnc`](#add-a-number) or in the console. Entries from before sources were kept read as `manual`. |
| `caller_request` | The person asked on a call not to be called again. After every connected phone call we check the conversation for this, and add the number with the call's id and the person's words. |
| `complaint` | The person filed a TRAI UCC complaint about an unwanted call from your workspace. No workspace on the platform can call them again, and the entry cannot be removed. |

Each addition sends a [`dnc.added`](#webhook-events) event to your webhook
subscriptions, so your other channels can stop too.

## The entry object

```json
{
  "object": "dnc_entry",
  "phone": "+919876543210",
  "created_at": "2026-11-21T09:31:12Z",
  "source": "caller_request",
  "call_id": "call_01KAF3K7N9P1R3T5V7X9Z1B3D5",
  "note": "दोबारा फोन मत करना"
}
```

| Field | Description |
| :--- | :--- |
| `phone` | The number, E.164. |
| `created_at` | When it was added. |
| `source` | `manual`, `caller_request` or `complaint`. See [how numbers get on the list](#how-numbers-get-on-the-list). |
| `call_id` | On `caller_request`: the call the person asked on. |
| `note` | On `caller_request`: the person's own words. On `complaint`: the complaint's reference. Absent when there is none. |

## Add a number

```http
POST /v2/dnc
```

```bash
curl -X POST https://sandbox.voice.miraiminds.co/v2/dnc \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "phone": "+919876543210" }'
```

```json title="201 Created"
{ "object": "dnc_entry", "phone": "+919876543210", "added": true }
```

Adding a number that is already on the list is **not an error**, because the
number is already suppressed. You get `200 OK` with `"added": false` instead of
`201`:

```json title="200 OK — already on the list"
{ "object": "dnc_entry", "phone": "+919876543210", "added": false }
```

If you keep your own count, branch on `added`. If you only need the number
suppressed, you can ignore it. Both responses mean the number will not be
dialled.

| Status | `error.code` | Cause |
| :--- | :--- | :--- |
| `400` | `invalid_request` | `phone` is not E.164. Send `+919876543210`, not `9876543210`. |
| `503` | `campaigns_unavailable` | Campaigns (and with them this list) are not enabled for your workspace. |

## List numbers

```http
GET /v2/dnc?limit=&cursor=
```

```bash
curl -G https://sandbox.voice.miraiminds.co/v2/dnc \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY" \
  --data-urlencode "limit=100"
```

```json title="200 OK"
{
  "data": [
    { "object": "dnc_entry", "phone": "+919876543210", "created_at": "2026-11-21T09:31:12Z",
      "source": "caller_request", "call_id": "call_01KAF3K7N9P1R3T5V7X9Z1B3D5", "note": "दोबारा फोन मत करना" },
    { "object": "dnc_entry", "phone": "+919812345678", "created_at": "2026-08-09T16:02:55Z", "source": "manual" }
  ],
  "has_more": false,
  "next_cursor": null
}
```

This route uses standard [pagination](/v2/overview#pagination): `limit` from 1
to 100 (default 20), and `cursor` from `next_cursor`.

## Remove a number

```http
DELETE /v2/dnc/{phone}
```

The number goes in the path, URL-encoded, so `+` becomes `%2B`.

```bash
curl -X DELETE "https://sandbox.voice.miraiminds.co/v2/dnc/%2B919876543210" \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY"
```

A successful delete returns `204 No Content` and sends a
[`dnc.removed`](#webhook-events) event.

| Status | `error.code` | Cause |
| :--- | :--- | :--- |
| `404` | `not_found` | The number was not on the list. |
| `409` | `do_not_call_complaint` | The person filed a TRAI complaint. The number stays on the list and can't be removed. |

<Warning>
**Removing a number un-suppresses it immediately.** Contacts already marked
`suppressed` in a campaign stay marked, because that status records a decision
already taken. Any future call or campaign, and any contact not yet claimed, will dial
the number. Keep an audit trail of who removed each number. If a reversed
opt-out leads to a complaint, you will be asked about it.
</Warning>

## Webhook events

Subscribe a [webhook endpoint](/v2/webhook-subscriptions#do-not-call-list) to
`dnc.added` and `dnc.removed` with a workspace subscription
(`"scope": {"type": "workspace"}`). They are signed and retried like every
other event.

| Type | Fires when |
| :--- | :--- |
| `dnc.added` | A number was added: by you (`POST /v2/dnc` or the console), because the person asked on a call not to be called again, or because they filed a complaint about one of your calls. |
| `dnc.removed` | A number was taken off (`DELETE /v2/dnc/{phone}` or the console). Your calls can ring it again. |

```json title="dnc.added"
{
  "id": "evt_5c2e…",
  "type": "dnc.added",
  "created_at": "2026-11-21T09:31:12Z",
  "schema_version": "2026-09-22",
  "workspace_id": "ws_…",
  "subject": { "type": "dnc_entry", "id": "+919876543210" },
  "source_id": "dnc:+919876543210:2026-11-21T09:31:12.481Z",
  "test": false,
  "data": {
    "workspace_id": "ws_…",
    "phone": "+919876543210",
    "source": "caller_request",
    "call_id": "call_01KAF3K7N9P1R3T5V7X9Z1B3D5",
    "note": "दोबारा फोन मत करना",
    "added_at": "2026-11-21T09:31:12Z"
  }
}
```

`data` has the entry's `phone`, `source`, `call_id` and `note` as above, and
`added_at`. `dnc.removed` adds `removed_at`. You get one `dnc.added` each time a
number is added. Adding a number that is already on the list sends nothing, and
a number added again after it was removed sends a new event.

## Keeping it in sync

The list is a set of numbers and the operations are idempotent, so the simplest
integration is also correct: on every opt-out event in your own system, `POST`
the number. You don't need to read the list first or diff it against yours.

```python
def on_opt_out(phone: str) -> None:
    r = httpx.post(f"{API}/v2/dnc", headers=auth, json={"phone": phone}, timeout=30)
    if r.status_code not in (200, 201):
        raise RuntimeError(r.json()["error"]["message"])
    # 201 -> newly added, 200 -> already there. Both mean suppressed.
```

We recommend three habits:

1. **Stop every channel at once.** When a person says "stop calling me" on a
   phone call, we add the number for you after the call. Listen for
   `dnc.added` and put the person on your WhatsApp, SMS and email stop lists in
   the same minute.
2. **Suppress before you upload.** Scrub each contact list before you upload
   it, *and* keep the DNC list current. If you forget to scrub a campaign's
   list, the DNC list still keeps those numbers from being dialled.
3. **Never remove in bulk.** Remove numbers one at a time, deliberately, and
   log a reason for each removal.
