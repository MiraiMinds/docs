## Authentication

Every request carries one header:

```bash
Authorization: Bearer sk_live_YOUR_API_KEY
```

A secret key is `sk_live_` followed by 32 hex characters. It is scoped to one
workspace. A key created after your company goes live carries your plan's
[tier](/general/tiers): T5 (pay as you go) unless you have committed to T3 or
T1. You create, rotate and revoke keys yourself in the
[console](https://sandbox.voice.miraiminds.co) under **Developers**.

We store only the SHA-256 of your key, so we cannot recover a lost key. Rotate
it instead. Never ship a secret key to a browser or a mobile app.

| Situation | Status | `error.code` |
| :--- | :--- | :--- |
| Header missing or key unknown | `401` | `unauthorized` |
| Key revoked | `403` | `forbidden` |

## Conventions

**JSON only.** Send `Content-Type: application/json` on every request with a
body. Responses are always JSON, including errors.

**IDs are minted by the server** and prefixed by resource type. Treat them as
opaque strings and don't parse them.

| Resource | Format | Example |
| :--- | :--- | :--- |
| Agent | `agt_<ulid>` | `agt_01K7Q9F3K7M2N5P9R4T6V8W0XZ` |
| Call | `call_<ulid>` | `call_01K7Q9B4M8N3P6R2S5T7V9W1YA` |
| Campaign | `cmp_<ulid>` | `cmp_01K7QAC5N9P4R7S3T6V8W2X4YB` |
| Offline transcription | `trn_<ulid>` | `trn_01M3XRSFXW77RHEQ85979AJXAF` |
| Webhook event | `evt_<ulid>` | `evt_01K7QC5N9P4R7S3T6V8W2X4YB` |

**Errors** normally use the envelope below. [Tool validation](/v2/tools#validation-and-runtime-errors)
returns a list of field errors. See the full [error reference](/v2/errors).

```json
{
  "error": {
    "code": "insufficient_balance",
    "message": "wallet balance 0.40 INR is below the minimum for one minute at t3"
  }
}
```

**Timestamps** are RFC 3339 in UTC: `2026-07-26T09:14:02Z`.

**Money** is in INR. `cost_inr`, `balance_inr` and `amount_inr` are numbers,
not strings. The one exception is [campaigns](/v2/campaigns), whose
`budget_paise` and `spent_paise` are integer **paise** (100 paise = ₹1). No
object mixes the two units.

**Phone numbers** are E.164 with the leading `+`: `+919876543210`.

## Pagination

List endpoints take `limit` and `cursor` and return a cursor-paginated envelope.

```bash
curl "https://sandbox.voice.miraiminds.co/v2/calls?limit=50&cursor=call_01JZQ9B4M8N3P6R2S5T7V9W1YA" \
  -H "Authorization: Bearer sk_live_YOUR_API_KEY"
```

```json
{
  "data": [ { "id": "call_01JZQ9B4M8N3P6R2S5T7V9W1YA", "…": "…" } ],
  "has_more": true,
  "next_cursor": "call_01JZQ9B4M8N3P6R2S5T7V9W1YB"
}
```

Pass `next_cursor` back as `cursor` to get the following page. Stop when
`has_more` is `false`. Default `limit` is 20, maximum 100.

## Idempotency

`POST /v2/calls` accepts an `Idempotency-Key` header. If you reuse a key, you get
the original response back instead of a second phone call. We hold keys for 24
hours.

```bash
-H "Idempotency-Key: order-8842-reminder-1"
```

Derive the key from your own domain object, such as an order ID or a job ID,
instead of generating a random UUID for each attempt. That way a retry sends
the same key. See [Calls](/v2/calls#idempotency).

## Not built yet

The API places outbound calls. These are the known gaps, so you can check them
before you start building:

- **Inbound calls.** Outbound only.
- **Buying phone numbers.** We provide the line.
- **Knowledge base / RAG**. For function calling, use [v2 tools](/v2/tools).
- **Wallet top-up over the API.** Add credit from the **Billing** page of the
  console instead.
- **OAuth or user-scoped tokens.** Secret keys only.

If one of these blocks you, tell us. Several are on the
[roadmap](/general/roadmap), and the order is not fixed.
